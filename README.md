# Gestionale termoidraulico

Web app gestionale (MVP) per un'azienda termoidraulica: rapportini digitali per i
tecnici in furgone, planning giornaliero per l'ufficio, calcolo dei totali con
export per il commercialista, scadenzario delle manutenzioni e dashboard dei
margini per il titolare.

## Stato

In progettazione. Il design approvato e il piano di implementazione stanno in
`docs/superpowers/`; il codice arriva con l'esecuzione del piano.

## Stack

Next.js (App Router, TypeScript), Tailwind CSS, Supabase (Postgres, Auth,
Storage, Realtime), Vitest e Playwright.
